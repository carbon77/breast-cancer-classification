# breast-cancer-classification
Классификация опухолей молочной железы по данным УЗИ

## Статистика BUSI (UNI-40)

Откройте [ноутбук](notebooks/01_eda.ipynb) в [Google Colab](https://colab.research.google.com/github/carbon77/breast-cancer-classification/blob/main/notebooks/01_eda.ipynb), выберите «Выполнить все» и разрешите доступ к Google Drive. GPU не требуется; зависимости доступны в стандартной среде Colab.

Данные берутся из `My Drive/colab/data/busi` с папками `normal`, `benign`, `malignant` и копируются в `/content/busi`. Исходные файлы на Drive не изменяются.

Ноутбук показывает количество и доли классов, статистику размеров и каналов, графики и примеры снимков. Файлы с `_mask` в имени исключаются из статистики классификации согласно [документации](docs/baseline-experiment-plan.md). Проверки папок, формата, целостности, масок и дубликатов не выполняются. Split и обучение в ноутбук не входят.

Результаты остаются в выводах ячеек. Для сохранения фактической статистики сохраните копию выполненного ноутбука с выводами в Colab. Локальная копия датасета удаляется при завершении сессии.
